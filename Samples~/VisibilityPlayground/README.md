# Visibility Playground

Import this sample, open VisibilityPlayground.unity and press Play.
Use Show all / Hide all rapidly to reverse in-flight animations. Restore now
cancels playback; destroying an object is deferred until its exit finishes.
Hide and pool returns the first visible object to a pool only after its exit;
Show all reuses those existing objects and cancels pending returns.
The controls remain active even when every target is disabled.

The sample alternates scale and slide on 100 cubes. Change objectCount in the
Inspector before Play (up to 1,000). This is a stress/behavior demo, not a
hardware performance guarantee. The package's editor preview additionally
demonstrates UI fade and combined scale/fade without editing the scene.

Use the Tweens tool in Deucarian Control Center for profile previews.

The built-in renderer uses Standard; URP uses its Lit shader. Assign Preview
Material in the Inspector when testing another render pipeline. The sample only
destroys materials it creates, never an assigned project asset.
